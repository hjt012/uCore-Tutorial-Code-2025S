## 二、问答题

### Q1: 什么是系统调用？它在 RISC-V 中如何实现？

系统调用（syscall）是操作系统提供给应用程序的一系列接口，使得应用程序能够使用操作系统的功能。本质上属于一种异常/中断，在 RISC-V 的汇编指令中以 `ecall` 的形式出现。操作系统通过区分 syscall 的 ID 来判断是哪一个 syscall 并执行对应的处理函数。

### Q2: RustSBI 的作用是什么？

RustSBI 是 RISC-V 架构下的 Supervisor Binary Interface 实现，运行在机器模式（M-mode），为运行在 Supervisor 模式（S-mode）的操作系统内核提供底层服务。它相当于操作系统内核的"执行环境"，负责处理机器模式下的初始化、时钟中断代理、以及提供控制台输入输出等基础功能。
